Supplementary Code and Data for the Paper "The LeBrun–Salamon conjecture is true in dimensions up to 56"

Authors: Aron Gohr, Marie-Amelie Lawn, Travis Schedler and Jordi Daura Serrano.

The repository contains exact Python checks of the finite identities and a Lean development of conditional symmetry results for compact connected positive quaternionic-Kähler manifolds.

Run the Python checks

Python 3.10 or later is sufficient. No third-party packages or Lean installation are required. From the repository root:

python3 -B python/check_all.py

The scripts reconstruct index densities, verify positive polynomial certificates and cone separators, and check the rational one-square witnesses in dimensions 13 and 14. All arithmetic is exact. Individual commands and normalization conventions are documented in python/README.md.

Build the Lean development

Install Lean and elan, then run:

cd lean
lake exe cache get
lake build
lake env lean -j1 -M8192 Audit.lean

The project pins Lean 4.28.0 and mathlib v4.28.0. Initial setup downloads the toolchain and dependencies. Later builds can run offline when these files are cached. For editor support, open lean/ in VS Code with the Lean 4 extension.

Mathematical scope

The Lean endpoints prove intrinsic symmetry of the given metric for quaternionic dimensions 1–12, and through 14 with an additional Amann intersection premise. They assume 15 explicit literature inputs and a separate four-dimensional input. The conclusion is global metric point symmetry; the endpoints do not enumerate Wolf spaces.

The Python scripts verify polynomial identities and coefficient signs. The geometric interpretations and literature inputs are separate from these calculations. The exact endpoint statements and source comparisons are available in the Lean explorer.

Offline browsing

Open this file directly in a browser, or open site/lean/index.html for the code comparison and search. No server, external assets, or JavaScript packages are required. Alternatively, from the repository root:

python3 -m http.server 8000 --directory site

Then visit http://localhost:8000/. Bibliographic links open external publications.
